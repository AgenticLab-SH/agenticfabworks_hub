Notion 일괄 반영

웹에서는 실시간 저장, Notion에는 사용자가 승인할 때 한 번에 반영하는 구조입니다.
Notion 대시보드 열기
웹과 Notion의 역할 분리웹 수정은 즉시 localStorage에 반영합니다. Notion은 매 입력마다 쓰지 않고, 반영할 시점에 전체 스냅샷을 한 번 생성하도록 했습니다. 공개 GitHub Pages에는 Notion 비밀 토큰을 넣지 않으므로 현재 버튼은 안전한 일괄 반영용 JSON을 만듭니다. 완전한 원클릭 동기화는 서버 중계층을 붙인 뒤 연결합니다.
